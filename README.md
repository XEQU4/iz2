<h1 align="center">IZ2</h1>

IZ2 — дипломный проект для анализа связей между участниками государственных
закупок Казахстана. Он помогает исследователям и специалистам по закупкам
просматривать компании, людей и контракты, находить связи и проверять их источники.

## Возможности

- Поиск компаний, людей и контрактов с указанием источников и дат получения сведений.
- Группы связанных компаний: причина объединения, приоритет проверки и полнота данных.
- Интерактивный граф с фильтрами, просмотром доказательств и историей сохранённых версий.
- Объяснения по сохранённым фактам: шаблоны и опциональная генерация через локальный Qwen.
- Аккаунты с сохранением, восстановлением и удалением персональных настроек графа.
- Интерфейс EN/RU и документированный JSON API со Swagger на английском.

## Быстрый запуск

Для новой пустой установки нужны Docker с Linux-контейнерами,
Docker Compose 2.24.4+ и Python 3.13+. Команды выполняются из корня репозитория.
На Windows вместо `python3` используйте `python` или `.\.venv\Scripts\python.exe`.

Подготовьте приватную конфигурацию и запустите приложение:

```sh
python3 scripts/prepare_deploy.py --project iz2 --output .env.docker --ai template
docker compose --env-file .env.docker config --quiet
docker compose --env-file .env.docker up --build -d --wait
docker compose --env-file .env.docker ps -a
```

Откройте [сайт](http://127.0.0.1:8000/app/) или
[API reference](http://127.0.0.1:8000/api/v1/docs/).
Режим `template` работает без скачивания модели.

Установка начинается с пустой базы: сбор данных и автоматические задания ИИ
по умолчанию отключены. Их настройка описана в [инструкции запуска](DEPLOY.md).
Существующая локальная база не переносится автоматически; сначала выполните
[перенос данных](DEPLOY.md#transfer-the-native-database-before-starting-the-application).
Сохраните созданный `.env.docker` и имя проекта: повторная подготовка не
перезаписывает файл, а другое имя проекта выбирает другие Docker-тома.
