IZ2 — дипломный прототип для исследователей и специалистов по закупкам. Он объединяет сохранённые записи о компаниях, людях и контрактах, чтобы можно было изучать связи, проверять их источники и выбирать, что требует дополнительной проверки.

<img src="docs/assets/overview.png" width="1100" alt="Обзор IZ2 с серебристой луной, звёздным фоном и счётчиками сохранённых записей">

Все скриншоты показывают вымышленные демонстрационные данные из отдельной базы. Рабочих записей и секретов на них нет; эти примеры не загружаются при установке.

## Возможности

- **Находите участников:** ищите компании, людей и контракты, изучайте исходные записи и даты.
- **Прослеживайте связи:** смотрите группы компаний, подтверждающие сведения и рассчитанный по правилам приоритет проверки.
- **Исследуйте граф:** фильтруйте связи, выбирайте узлы и изучайте панель доказательств.
- **Возвращайтесь к сохранённым версиям:** сопоставляйте снимки графа, историю групп и сохранённые результаты анализа.
- **Читайте объяснения:** изучайте шаблоны по сохранённым фактам или опциональные объяснения локального Qwen, прошедшие проверку привязки к доказательствам.
- **Настраивайте рабочее пространство:** сохраняйте, восстанавливайте и удаляйте личные раскладки графа; переключайте интерфейс между русским и английским.

## Быстрый запуск

Для **новой пустой установки** нужны Git, Python 3.13+ и Docker с Linux-контейнерами и Compose 2.24.4+. Node и зависимости приложения устанавливаются при сборке образа. На Windows используйте `python` вместо `python3`.

```sh
git clone https://github.com/XEQU4/iz2.git
cd iz2
python3 scripts/prepare_deploy.py --project iz2 --output .env.docker --ai template
docker compose --env-file .env.docker config --quiet
docker compose --env-file .env.docker up --build -d --wait
docker compose --env-file .env.docker ps -a
```

Откройте [сайт](http://127.0.0.1:8000/app/) или [документацию API](http://127.0.0.1:8000/api/v1/docs/).

Режим шаблонов не требует скачивания модели. База изначально пустая; сбор данных и автоматические задания ИИ отключены. Храните `.env.docker` приватно. Помощник не перезаписывает этот файл; сохраняйте имя проекта, поскольку оно определяет Docker-тома. Для существующей локальной базы выполните [перенос данных](DEPLOY.md#transfer-the-native-database-before-starting-the-application) до запуска приложения.

## Ограничения

- Общий контакт или группа связанных компаний не доказывают сговор. Приоритет проверки — детерминированный индекс, а не калиброванная вероятность или валидированный ML-детектор.
- Источники охватывают не все сведения. Отсутствие проверки не означает отсутствие проблемы; даты источников и пробелы в доказательствах остаются видимыми.
- Это дипломный прототип для работы под наблюдением, а не автономный публичный сервис. Нерешённые вопросы перечислены в [текущем аудите](docs/FINAL_AUDIT.md).
